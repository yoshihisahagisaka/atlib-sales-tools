# 実施手順（かんたん版）: sales-tools デプロイ

最終更新: 2026-08-23
対応する詳細仕様書: `sales-tools/docs/運用手順書_デプロイ.md`

## これは何の作業か

原価見積ツール・ISMS診断フォーム（`sales-tools`）のコード変更を、実際に動いているCloud Runサービスに反映させる作業。テーブルの追加・変更（マイグレーション）が無い場合は「手順1」だけで終わる。

## 始める前に

- `gcloud`コマンドが使え、`msp-zabbix`プロジェクトへのCloud Runデプロイ権限がある端末が必要
- コードの変更は事前にGitHubへpush済みであること

---

## 手順1: 通常のデプロイ（テーブル変更が無い場合・ほとんどの場合はこれだけ）

1. **画面/コマンド**: `sales-tools`ディレクトリで以下をそのまま実行する
   ```bash
   gcloud run deploy sales-tools --source=. --region=asia-northeast1 --project=msp-zabbix
   ```
2. **確認**: デプロイが正常終了し、`Service URL`が表示されること
3. **操作（反映確認）**: 表示されたURL（または独自ドメイン）に対して以下を実行する
   ```bash
   curl -sk -o /dev/null -w 'HTTP %{http_code}\n' https://<URL>/healthz
   ```
4. **確認**: `HTTP 200`と表示されれば反映成功

`migrations/`配下にファイルを追加した場合のみ必要。詳細仕様書の手順2を参照。

## うまくいかない場合

### デプロイコマンドが権限エラーで失敗する

自分では直せない。担当エンジニアに連絡する（IAM権限の付与が必要な可能性がある）。

### `/healthz`が200を返さない

しばらく待って再度確認する（デプロイ直後は起動に数十秒かかることがある）。それでも直らない場合は担当エンジニアに連絡する。
