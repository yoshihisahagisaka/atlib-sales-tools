# SECU:MIE Insight HA-1 手動レビュー

## 起動と停止

PowerShellでリポジトリ直下から起動する。

```powershell
.\Start-PiraHaReview.ps1
```

- URL: `http://127.0.0.1:4173/pira/pira-e2.html`
- レビュー用認証コード: `246810`
- メールアドレスと企業情報にはテストデータだけを使用する。

停止時:

```powershell
.\Stop-PiraHaReview.ps1
```

停止スクリプトはPIDとコマンド行を照合し、HA-1用プロセスだけを停止する。

## 操作順序

1. テスト用メールアドレスを入力し、認証コード送信を押す。
2. `246810` を入力して認証する。
3. 企業情報F01〜F07をテスト値で入力する。
4. `PIRA-UNION-CONSENT-V1.0` の国連協同意文言を確認し、同意する。
5. 診断を開始し、「セルフチェックをはじめる」の後に既存8問の最初の質問が表示されることを確認する。

## モック境界

実物を使用するもの:

- OTP画面と画面遷移
- 企業情報F01〜F07、国連協同意文言、診断接続コード
- 既存8問、38回答ID、C方式、v7レポート描画

HA-1限定の代替:

- TurnstileはHA-1サーバーがローカルトークンを画面に供給する。本番Turnstile実装は変更しない。
- SMTPを使用せず、認証コードを `246810` に固定する。
- RS256/JWKS/jtiはレビュー用トークンで代替する。
- Cloud SQLには接続せず、受付状態はプロセスのメモリ内だけに隔離し、停止時に破棄する。
- Production、Cloud Run、Cloud SQL、Secret、DNS、既存Sales Toolsと通信しない。
