- Decision date: 2026-10-21
- Status: **DECIDED（事業・設計方針）**
- Scope: PIRA組合向け施策、組合所属企業向け展開、将来のatLIB公式サイト無料診断
- Reference: Draft PR #15（設計）、Draft PR #16（Phase 3試作品、確認時点 e824db4）、Corporate Issue #43

## 1. 目的と基本思想

本施策の主目的は「正しいセキュリティ診断」や安全性の採点・認証ではない。**診断というイベントを通して回答者に業務・関心・疑問を振り返ってもらい、atLIBがIT専門家として知っておいてほしい情報資産保護の知識を、回答者の業務に結び付けてわかりやすく届けること**である。

回答を根拠なく推測・断定しないことは信頼性の前提であって、採点自体を目的としない。「回答 → 理解・気づき → 必要な行動・実務資料」を提供価値の中心とする。既に対策を実施している回答者にも、その対策の意味を解説する価値がある。

## 2. 設計順序（従来からの転換）

従来の「質問 → 実施状況判定 → 指摘 → 説明」から、以下へ転換する。

1. **伝えたい知識・重要性・事故の仕組み・業務への影響を定義する**
2. それをわかりやすく伝える**完成解説原稿**を作成・レビューする
3. その解説を適切に届けるための**質問・回答選択肢**を逆算して設計する
4. 回答と業務の関連性に応じた**解説選択ルール**を確定する
5. HTML／PDFレポートと実務資料を提供する
6. 企業向けでは、必要に応じて関連する支援方法と任意相談を案内する

**解説を届けることから逆算して判定ロジック・質問を設計してよい。** 既存T01〜T08のテーマ順・最大3件などは現行実装仕様であり、将来設計の無条件の制約とはしない。変更時は別途仕様確定・回帰検証する。

## 3. 確定論的方式と品質

- 実行時AIによる文章自由生成は行わない。専門家が事前に作成・確認した固定文章を版管理し、確定ルールで選択する。
- 回答から実施状況が不明なものを「未実施」と決めつけない。業務や情報保有を推測しない。
- **実施状況の整理**と**理解してもらう価値が高い解説の選択**を分離する。不明・担当外・実施済みでも、関連する知識の説明対象になり得る。
- テーマの選択では業務との関連性、伝える価値、事故時の業務影響、説明の重複を考慮する。単純な「未実施の先頭3件」を最終的な事業要件としない。
- 解説は「事故・トラブルの仕組み → 自分たちの業務への影響 → 対策の意味 → 回答に応じた具体的な確認」を基本とする。
- 例：ランサムウェアはデータを暗号化して金銭を要求する。被害を受けていないバックアップから復元できれば攻撃者の復号に頼らず復旧できる可能性がある。ただし情報流出の影響は別途残り得る。
- 内部設計用語、不要な言い訳、根拠のない断定、恐怖訴求、商品自動推薦を避ける。
- 文章と質問・判定ロジックの**両方**を本意思決定レーンでレビュー・確定してからWorkに実装を委ねる。Workに事業思想や完成文章の独自決定を委ねない。

## 4. 対象別の導線・ゴール

### A. PIRA（一般社団法人 国際連携推進協会／国連協）組合向け：最優先

アンケート → 回答に応じた解説選択 → 個別解説レポート → 実務資料（HTML・PDF・Excel等）。

**レポートと実務資料の提供自体をゴール**とする。関連商品・無料相談への誘導を必須とせず、営業色を出さない。組合の専門領域である外国人材制度の指導は行わず、atLIBのIT・情報資産保護の専門知識に集中する。

国連協のキーパーソンK氏の取り組みに協力し、組合が価値を実感できることを優先する。国連協が所属企業への配布を担う際も、組合専用URLを単純転送する構成を前提としない。

### B. 組合所属企業向け：将来展開

**アンケート → 診断・解説選択 → 個別解説レポート → 関連サービス紹介 → 任意の問い合わせ・無料相談**。

まず知識・気づきを届け、関連サービスは理解の後に自然に紹介する。企業情報・流入元は適切な同意と目的明示のもとで取得する。実際の提案は相談時に企業環境を確認して行い、回答のみで商品の必要性を断定しない。

### C. 一般企業向け：将来展開

PIRA施策で得た共通資産を活かし、**atLIBコーポレートサイトの無料診断サービス**として一般中小企業・既存顧客・紹介先へ展開する可能性を保持する。企業向け導線はBと同じ思想。現時点で一般公開・実装着手を承認したものではない。

## 5. 関連サービスとの関係

知識提供から自然に接続し得る例：バックアップ／復元・リモート運用、MFA・Microsoft 365／Google Workspace管理、Windows Update・端末管理、Secure Guard、Secure Send、ネットワーク防御、情シス運用、業務KAIZEN（紙・Excel・API連携・Webシステム化）、IT経営KAIZEN等。

**診断結果から特定製品を自動推奨しない。** サービスは選択肢として紹介し、問い合わせ・相談は任意。atLIBが企業の実態に合わせて提案する。

## 6. 共通資産と実装方針

再利用対象：知識・解説原稿、質問と解説の対応、確定選択ルール、HTML／PDF表示、実務資料、版管理、検証ケース。対象ごとに変えるもの：質問の業務例・順序、表示ブランド、関連サービス・相談導線、必要な同意・流入元管理。

PIRA向け完成を最優先とし、将来のためだけに大規模な共通プラットフォームを先行開発しない。既存IT経営KAIZEN・業務KAIZEN・マーケティング管理の再利用可能な思想・実装を確認し、重複開発を避ける。
